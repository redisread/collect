# 阅读界面与布局优化计划

## 范围

落实本次界面审查的十四项建议，覆盖移动阅读导航、弹窗、笔记、订阅源、设置、认证表单和动效。保留黄色主题，复用现有 Framer Motion 12。

## 实现决策

- 共用原生 dialog 外壳，负责模态焦点、Escape、关闭后焦点返回和短屏滚动。内容与业务操作留在各组件。
- 阅读导航在手机保持单行，设置与订阅源通过明确的更多入口访问。
- 桌面分栏按容器宽度约束，优先保障 400px 阅读栏，兼容已有持久化宽度。
- 设置采用页内分区导航，保留表单草稿和账号偏好保存流程。
- 封面与正文首图地址相同时省略额外封面，保留正文及图注。
- 动效采用短时淡入和轻微位移，减少动态效果时取消位移与回弹。主题切换暂停过渡。

## 任务顺序

1. 弹窗与笔记的可达性
2. 移动导航与桌面宽度约束
3. 订阅源名称和移动入口
4. 封面去重
5. 个人设置与认证表单
6. 动效和主题一致性
7. 验证、PR 和独立双轴审查

每两至三个任务运行聚焦验证。详细验收条件见 todo.md。

## 风险与验证

- 原生 dialog 须在真实浏览器验证焦点、Escape、嵌套滚动和短屏。
- 封面去重仅基于明确匹配，避免删去不同图片。
- 浏览器扩展可能注入翻译和悬浮控件，使用本地测试数据验证应用自身布局。
- 浏览器尺寸模拟与真实 iPhone/PWA 验收分别报告。
- PR 按 AGENTS.md 创建后执行 Standards 与 Spec 独立审查，必要验证和 CI 通过后判断合并。

## 新增 #32 的诊断
生产只读查询确认账号最大订阅数为 119。原列表查询将订阅 ID 展开为绑定参数，超过 D1 限制。119 个额外订阅的真实 SQLite/D1 限制测试在修复前返回 500。改为 SQL 子查询保持账号与来源筛选，参数数量恒定。客户端保留独立列表错误状态，提供重试，失败时显示加载失败。

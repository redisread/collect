# 自定义 AI 翻译设置

用户已确认执行，2026-11-08。

## 已确认

- 个人设置支持 OpenAI 兼容接口，用户可填写 API 地址、模型名和 API key。
- 提供 DeepSeek 快捷配置，自动填入官方地址与推荐模型，具体值在实施时核对官方文档。
- 密钥随账号加密保存在服务端，网页和 PWA 共用。设置接口返回配置状态，支持替换与删除密钥。
- 翻译请求由服务端使用用户配置的凭据发送，文章交给所选服务商处理，消耗用户的 API 额度。
- 结合文章上下文分段翻译，逐段展示，支持全文、双语和失败段落重试。
- 翻译目标语言继续作为账号偏好，保存后在下次翻译时生效。
- 支持保存多套 AI 翻译配置，由用户选择当前使用的一套。
- 保留 Google 翻译，允许用户手动切换。
- 已完成的 AI 翻译段落随账号保存，手机切后台、锁屏或刷新后可手动继续剩余段落。
- Google 与各套 AI 配置全部在个人设置中切换，文章顶部保留翻译操作及当前服务提示。
- 尚未配置 AI 的账号默认 Google，新增 AI 配置可“保存并启用”。AI 调用失败时，由用户手动决定是否切回 Google。
- 切换服务或配置后，下次翻译生效，当前阅读视图保留。
- 按文章内容、目标语言和 AI 配置分别保存译文与进度，切回原配置可以继续。修改模型或翻译地址后生成新译文。

## 实施与验收

- 个人设置覆盖多配置新增、编辑、启用、删除以及密钥配置状态，DeepSeek 快捷填写、连接测试和明确的加载及错误反馈。
- 服务端按账号隔离配置、密钥、译文和进度。密钥加密存储，页面读取仅返回已配置状态。
- 自定义接口使用可从 Worker 访问的公网 HTTPS 地址。请求需验证目标地址、限制重定向，并保护访问凭据。
- AI 按段返回翻译结果，保留文章结构和双语对应关系。未完成段落提供继续或重试，完整译文与部分进度明确区分。
- 验证配置切换、原文更新、语言修改、密钥替换、请求失败、取消以及刷新后继续，防止混用译文或重复覆盖进度。
- 验证手机窄屏、网页及 PWA 共用入口与偏好，记录实机验证范围。
- 按 AGENTS.md 完成验证、PR、双轴子代理审查与合并部署。

## 实现约定

- OpenAI 兼容服务使用 Chat Completions。DeepSeek 预设地址为 `https://api.deepseek.com`、模型为 `deepseek-flash`，显式关闭思考模式以减少翻译等待。自定义服务不发送 DeepSeek 扩展参数。[DeepSeek 官方接口](https://api-docs.deepseek.com/)
- API key 使用 AES-GCM 加密，关联数据绑定账号与配置 ID。独立 Worker secret `AI_KEYS_ENCRYPTION_SECRET` 为 Base64 编码的 32 字节随机值。密文携带版本，后续轮换需同时迁移密文，不能直接覆盖此 secret。
- `ai_profiles` 保存账号配置，`ai_translation_jobs` 保存文章内容哈希、配置版本、目标语言、原文拆分模板及已完成段落。修改名称或替换密钥保留翻译版本，修改地址、模型或服务类型生成新版本。
- 每次请求处理一个段落，客户端顺序拉取并显示结果，切后台后停止发起下一段请求。D1 条件更新取得 90 秒租约，单段总超时 55 秒。请求携带已完成段数，重复发送同一请求只返回已保存进度。
- 页面刷新后读取当前配置对应的已有进度，由用户手动继续。尚未翻译的内容保留原文，进度提示区分部分译文和完整译文。
- 删除配置会删除该配置的密钥与译文进度，页面先确认删除，当前配置被删除时切回 Google。
- Google 保留原有服务端与浏览器备用路径，其公共入口仍可能被限流或受到跨域限制。新增持久化逐段续译用于 AI 配置。

# iOS 订阅管理

## 已确认范围

- iOS 新增集中管理页，入口位于首页「订阅」标题右侧。管理数据与 Web 同步。
- 支持按名称和订阅地址搜索，创建、重命名、排序和删除文件夹。
- 支持新增订阅时选择目录，修改订阅名称、移动目录、设置全文提取和取消订阅。
- 支持多选批量移动和批量取消订阅。每批最多 50 项，批次失败后保留未完成选择，显示已完成数量并允许重试。
- 删除文件夹后将其订阅移至未分类，保留文章。未分类不能重命名或删除。
- 取消订阅前说明影响范围并确认，清理普通文章，保留收藏和稍后阅读及来源信息。
- 首次启动刷新一次，之后仅下拉刷新。管理操作应用响应结果，不额外全库刷新。

## 数据规则

取消订阅保留来源记录，设置取消时间并停用抓取。已取消的来源退出订阅目录和 OPML 导出，保留文章仍可在收藏、稍后阅读及全部文章中访问。删除文件夹与批量移动只影响属于当前账号的订阅。

重新订阅同一地址时恢复原来源，保留既有收藏和稍后阅读。用户主动重新订阅会重新收录该源当前提供的文章，自动抓取仍遵循已有的文章过期去重规则。数据库触发器拒绝取消订阅后的迟到抓取插入。

取消订阅先上传离线状态修改，上传失败时保留现状并提示重试，避免尚未同步的收藏丢失。服务器在同一事务中停用来源、清理普通文章并返回保留文章的最新元数据，客户端据此更新本地资料。

文件夹排序一次请求原子保存到账号数据。订阅重命名、移动和排序结果保持本地顺序稳定。进行中的保存禁用重复操作。Web 兼容已取消来源的隐藏、收藏计数和取消订阅提示。

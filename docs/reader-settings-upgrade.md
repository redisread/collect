# 阅读与个人设置改造

用户已确认全部方案，进入实施。

## 用户提出的范围

- iPhone 支持浅色、深色和跟随系统。
- 为指定订阅源开启原文拉取，设置在多端同步。
- 通过订阅源右键菜单移动文件夹，移除每个订阅源右侧的移动图标按钮。
- 在订阅源中一键将全部未读文章标记为已读。
- 文章保存期限绑定用户设置，默认 30 天，可选 7、30、60、90 天，最长 90 天。
- 支持设置和更新头像、用户名。
- 个人设置采用侧边 tab 布局。
- AI 服务商增加 GLM 快速配置。
- 排查并修复收藏异常。

## 已确认决策

- Q1 按推荐范围实施。原文拉取、批量已读、保存期限、个人资料、收藏修复覆盖 Web 与 iPhone，并同步账号数据。Web 用右键菜单、iPhone 用长按菜单移动订阅源。侧边 tab 设置布局和 GLM 快速配置入口先用于 Web。
- Q2 iPhone 提供跟随系统、浅色、深色。首次默认跟随系统，已有安装保留深色。外观按设备保存，正文阅读页同步切换外观。

- Q3 原文拉取定义为自动提取文章全文。新文章采集时提取，历史文章首次打开时补提取，失败保留 RSS 内容并支持重试。
- Q4 保存期限按首次采集时间计算，默认 30 天，可选 7、30、60、90 天。普通文章到期从服务端删除，各端同步清理，未读文章同样适用。收藏和稍后阅读持续保留。缩短期限时预览预计清理数量，用户确认后执行。
- Q5 在订阅源文章列表顶部和订阅源菜单提供全部标为已读，范围为操作时已有的全部未读文章。之后新到文章保留未读，iPhone 离线操作在联网后同步。
- Q6 头像支持上传、正方形裁剪和移除。用户名为显示名称，允许重名。Web 设置采用个人资料、阅读、AI 翻译、订阅导入导出四个侧边 tab，窄屏改为顶部导航。
- Q7 增加中国智谱 GLM 标准 API 预设，自动填写基础地址和默认模型，用户填写 API Key 后可测试连接，支持修改模型。
- Q8 修复收藏数量，收藏和稍后阅读默认同时展示已读与未读文章，验证连续点击、失败恢复及跨端同步。用户未提供额外复现步骤，按已确认缺陷和上述场景验收。

## 已核查现状

- Web 侧栏收藏和稍后阅读计数硬编码为 0。全局隐藏已读也会过滤收藏列表，用户未提供额外故障现象。
- 服务端已有订阅源全量标记已读接口，两端缺少界面入口。
- 原文提取当前主要由用户手动触发，缺少订阅源级自动提取配置。
- 现有服务端清理逻辑直接删除过期文章，只保护收藏。生产统一 Worker 尚未调度这项清理。
- 服务端文章期限按首次采集时计算。iPhone 另有按阅读或缓存时间计算的离线缓存清理策略。
- 用户资料已有姓名和头像字段，缺少编辑和上传入口。
- Web 外观当前按浏览器保存，个人设置采用单列锚点导航。
- AI 配置已有 DeepSeek 和自定义 OpenAI 兼容服务，缺少 GLM 专用预设。

## 数据清理边界

- Q9 现有文章获得从迁移执行时起 30 天过渡期，之后按所选期限清理。新采集文章使用正常期限。
- Q10 取消最后一种保护状态后给予 7 天宽限期。展示预计清理日期，重新收藏或加入稍后阅读可继续保留。

## 接口与实现约定

- 服务端每小时执行过期清理，通过删除触发器保留订阅源与文章 URL 的最小记录，阻止 RSS 轮询重新导入已清理文章。取消订阅时同步清除这些记录。
- 首次清理过渡期从生产迁移执行时计算。取消最后一种保护状态时，7 天宽限期与已有过渡期取较晚值。
- 头像在客户端裁剪为正方形 PNG，限制上传后文件 1 MB，使用账号隔离的 R2 路径保存与读取。
- Web 收藏及稍后阅读展示完整列表，普通列表保留原有隐藏已读设置。
- iPhone 批量已读将操作时已同步的未读文章一次性持久化，沿用逐字段版本冲突处理；后续同步到达的文章保持自身状态。
- 智谱快捷配置使用官方标准接口与 glm-5.3，翻译调用关闭思考模式。模型名称支持用户修改。

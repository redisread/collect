# 阅读体验优化

2026-11-07 用户确认以下范围。

- 订阅源支持拖入文件夹、跨文件夹移动和移回未分类。移动端和键盘用户可以使用“移动到”控件，保存失败恢复原位置。
- 品牌图标采用书页与地平线意象，黄色主题，统一网站 favicon、侧栏、登录和注册页标识。
- 点击文章立即显示极简加载状态，切换文章时只呈现最新请求结果；失败提供重试。
- 顶部操作分组适配窄屏，菜单应在可视区域内且不受父容器裁剪，支持键盘和减少动态效果偏好。
- 翻译使用免密钥 Google 入口，提供超时、错误提示和重试；失败结果不写入成功缓存。
- 全文缺失时先自动提取；失败后允许明确选择“仅翻译摘要”。
- 原文、双语、译文三个阅读视图复用翻译结果，默认原文，首次翻译完成进入双语，默认目标语言简体中文。
- 保留图片、链接、列表、代码结构，避免嵌套段落重复翻译。

验收包括移动失败回滚、加载竞态、翻译失败与长文、深浅主题、320px 窄屏、200% 缩放以及菜单可操作性。完成后依项目规则创建 PR、双轴审查并合并发布。

## 浏览器备用翻译与 PWA

2026-11-07 用户确认在服务器受到 Google 限流时，增加免费的浏览器直连备用入口，并要求 PWA 支持。

- 服务器翻译失败后提供“通过浏览器重试”，用户点击后由浏览器直接请求 Google 公共翻译入口，复用同一套段落和 HTML 结构保留逻辑。
- 备用请求使用 Google 公共接口，业务认证、文章和翻译历史继续使用同源 API。重试复用内存中的成功段落，切换文章取消正在进行的备用翻译。
- PWA 支持桌面与移动端安装、独立窗口、统一图标。当前离线能力为离线提示页。
- Service Worker 仅缓存公开的图标、manifest 和离线提示页。认证接口、文章数据和第三方请求按网络请求处理。
- 发布产生新版本的 Service Worker，用户选择“更新并刷新”后切换版本。
- 验收包含生产环境原失败文章的浏览器备用翻译、manifest 安装条件、离线提示和版本更新流程。

## 账号翻译偏好

2026-11-08 用户确认以下设置行为。

- 独立 `/settings` 页面从侧栏底部用户区进入，沿用黄色主题，覆盖桌面与窄屏。
- 目标语言跟随账号保存在 D1，缺失偏好的旧账号默认简体中文，网页与 PWA 共用。
- 文章顶部移除语言选择器，保留“翻译全文”，提示中显示当前目标语言。
- 保存后，下一次全文翻译、摘要翻译或浏览器重试采用新语言。正在执行的翻译继续使用启动时的语言。
- 进入设置再返回阅读，保留选中文章、滚动位置、阅读视图和不同语言的译文缓存。保存偏好本身不会发起翻译。
- 每次翻译前同步账号偏好，同步失败时允许重试。设置页提供加载、保存成功与失败反馈。
- 邮件摘要设置 API 的现有契约与移动客户端保持兼容。

2026-11-08 手机入口修正。手机网页与 PWA 的顶部在“订阅源”旁直接显示“个人设置”，在文章列表、阅读文章和展开订阅源时均可进入。窄屏顶部操作可以换行，返回阅读时焦点回到当前可见的设置入口。

## 手机正文滑动切换文章

2026-11-10 用户确认以下交互。

- 手机浏览器与安装后的 PWA 均支持正文左滑进入下一篇、右滑返回上一篇。
- 上一篇与下一篇按进入详情时的列表顺序定义，跟随账号选择的最新优先或最早优先。
- 屏幕边缘保留系统返回手势，横向滚动的图片、表格和代码块优先操作内容。

用户随后确认以下连续阅读规则。

- 本次阅读保留进入时的文章顺序。即使隐藏已读，读过 A 再进入 B，仍能右滑回到 A。返回列表后按隐藏已读更新列表。
- 接近已加载末尾时自动加载后续文章。真正到达首尾时停在当前文章并提示第一篇或最后一篇。加载失败保留当前正文并提供重试。
- 本次首次进入一篇文章从顶部开始，返回已看过的文章恢复滚动位置和原文、双语或译文视图。
- 正文轻微跟手移动，达到滑动距离后切换，否则回弹。遵循减少动态效果偏好，同时提供上一篇和下一篇按钮。

实现边界沿用进入详情时的来源和排序，正文切换与 J/K 共用连续阅读顺序。搜索入口以当前搜索结果为阅读范围。选择其他列表文章或返回列表后重新进入，会建立新的阅读顺序。文字选择、笔记和嵌入控件操作优先于切换手势。

验收覆盖隐藏已读后往返、跨越 30 篇分页、日期相同或缺失、首尾提示、失败重试、切换来源时的加载竞态、位置与视图恢复、竖向滚动及横向内容避让、移动和桌面宽度。
